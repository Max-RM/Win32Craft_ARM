# Win32Craft - A UWP wrapper designed to run "Minecraft: Windows 10 Edition" on Windows RT (8.1), Windows 10 ARM32 15035 and Windows 10/11 ARM64 as a Win32 app.

## Supported Versions (UWP ARM32)
- 1.2.8 (Experimental)

## Build
Platform|Script
---|---
Windows|build_windows_mingw.bat
Linux (cross-compilation to run in Wine)|./build_mingw.sh

### Patch Example
```
cd tools
python 0.13.2-patcher.py Minecraft.Win10.DX11.exe
```
