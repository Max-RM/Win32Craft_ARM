## Summary
Plain-language verdict for "Bad Piggies Rebooted" (Unity 2018.4.36f1, IL2CPP, ARM32 UWP):
1. It is NOT a XAML game. The 28 KB exe is Unity's standard "D3D / CoreWindow" bootstrap: wWinMain -> CoreApplication::Run -> its own IFrameworkView, which creates UnityPlayer.AppCallbacks and calls SetCoreApplicationViewEvents, SetCoreWindowEvents, InitializeD3DWindow and Run (nothing else). There is no MainPage, no XBF, no SwapChainPanel; the task header's "XAML build type" is wrong (F1, F2).
